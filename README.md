# PyCNC Studio

Software CNC modular desarrollado en Python.

El objetivo de este proyecto es crear una plataforma libre para controlar máquinas CNC utilizando diferentes controladores como Arduino, GRBL y otros sistemas compatibles.

---

# Objetivo del proyecto

Crear un software CNC moderno con:

- Interfaz gráfica
- Control de máquina
- Simulación CNC
- Interpretación de G-Code
- Comunicación con hardware
- Arquitectura modular
